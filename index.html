ER - Extension Repairer

An emergency room for Bondage Club add-ons

When a game update removes or changes something an add-on still uses, that add-on crashes or stops loading until its author updates it. ER puts a compatible stand-in back so your add-ons keep working. When the game or the add-on catches up, ER's fix switches itself off.

Install

1. Install Tampermonkey or Violentmonkey in your browser.

2. Install ER

Install once: every game load fetches the newest fixes. ER loads before your other add-ons, which some of them need. Type /er in a chat room to see what it is treating.
